# Voice recordings

Drop recordings here, named after their line id: `l0_greet_1.wav`, `l1_sealed.ogg`, and so on.
The ids, lines and directions are in [docs/script/recording-list.md](../../docs/script/recording-list.md).

The game plays a recording whenever one exists for a line and falls back to the timed subtitle when it doesn't,
so lines can be recorded a few at a time.
