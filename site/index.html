Opening it the first time

The game isn't signed with a paid developer certificate yet, so your computer asks once whether you trust it.

Windows

  1. Right-click the zip, choose Extract All, then open the folder. Keep the files in it together.
  2. Double-click NullAndVoid.
  3. If you see "Windows protected your PC", click More info, then Run anyway.
  4. If Windows asks whether the game may use networks, tick Private and Public and click Allow. Co-op needs it.

Mac

  1. Double-click the zip to unzip it, and drag Null & Void into Applications.
  2. Right-click (or Control-click) the game and choose Open, then Open again.
  3. If your Mac only offers Done or Move to Trash, click Done, open System Settings > Privacy & Security, scroll down, and click Open Anyway next to Null & Void.
  4. Allow the microphone if you want voice chat.

Linux

  1. Unzip it and run NullAndVoid.x86_64 from the folder.

After the first time, it opens like any other game.

Playing together

  • Same Wi-Fi, or solo: nothing extra. One player hosts, and everyone else joins the address the host's lobby shows.
  • Over the internet: we use Tailscale. It's free for this and puts everyone's computers on one private network, so the game works as if you shared Wi-Fi. Not sponsored, just our recommendation for playing together over the internet. Set it up once with our 10-minute guide.
